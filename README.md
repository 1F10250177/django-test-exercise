# Django Todo App

このプロジェクトは Django で構築した ToDo 管理アプリケーションです。

## デプロイ先

Render でデプロイ済みです。

- URL: https://django-test42-web.onrender.com/

## 概要

- ToDo の作成・編集・削除
- 優先度の管理
- Django の基本的な CRUD 機能の実装

## ローカルでの実行

```bash
python manage.py migrate
python manage.py runserver
```

ブラウザで http://127.0.0.1:8000/ にアクセスしてください。
